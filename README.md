### 📌 Featured Project

## 📦 Ledgerix — Spare Parts Audit Ledger

A full-stack application designed for **spare-parts inventory auditing and management**.

### Key Features

* 🔐 Proper authentication and user management
* 👤 Role-based access control with **ADMIN** and **USER** roles
* 📦 Spare-parts master management
* 📍 Location management
* 🧾 Physical stock counting
* 📊 Live counting sheet
* 🔎 Part search functionality
* 💰 Automatic stock-value calculations
* 📝 Remarks and audit records
* 💾 PostgreSQL-based persistent storage
* 🔒 Password hashing using bcrypt
* 🎯 Protected API routes
* 🛡️ Helmet security headers
* 🌐 Configured CORS
* 📤 Data backup and import/export functionality
* 📄 Planned reporting and PDF/print functionality

### Tech Used

**Frontend:** React.js, Vite, JavaScript
**Backend:** Node.js, Express.js
**Database:** PostgreSQL
**Authentication:** JWT + bcrypt
**Security:** Helmet, CORS, Rate Limiting
